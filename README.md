# 埼玉大学 博士前期課程 物理学PG 口述試験 問題集

埼玉大学大学院 博士前期課程 物理学プログラム（物理学PG）の口述試験対策用の問題集です。

## 使い方

1. `index.html` をブラウザで直接開く（ダブルクリックでOK）
2. 「熱・統計力学」「量子力学」のタブで科目を切り替える
3. 難易度・カテゴリでフィルタリングしながら問題を確認する
4. 問題文をクリックすると表示/非表示が切り替わる（解答前に考える時間を確保するため）
5. 解いた問題にチェックを入れて進捗を管理する

インストールや外部依存のセットアップは不要です。数式表示にはMathJax（CDN）を利用しています。

## 試験形式

- **試験時間**: 15分間
- **出題数**: 1問
- **解答方法**: ホワイトボードを用いた解説
- **科目**: 熱・統計力学、量子力学

## 問題構成

- **コンセプト**: 広く浅く（分野内の幅広いテーマを網羅）
- **問題タイプ**:
  1. 基本的な概念・原理の理解を問う問題
  2. 代表的な典型問題
  3. 複数の概念を組み合わせた総合問題
- **熱・統計力学50問、量子力学92問（計142問）**

### 難易度定義

- **基礎**: 定義・概念の確認、基本的な計算
- **標準**: 典型的な計算問題、理解を問う問題
- **応用**: 複数概念の組み合わせ、導出問題
